# Electric Optimization Project (Demo)

## 🟢 Context & Objective
Analysis of utility bill spikes and implementing behavior/equipment changes to reduce costs.

## 📝 Current Progress / Discussion
### 📊 Data Summary (Sample Data)
| Month | Amount | Usage | Daily Avg | Status |
| :--- | :--- | :--- | :--- | :--- |
| **Jan** | $460.00 | 2,350 kWh | 78.33 kWh | Peak Usage |
| **Feb** | $420.00 | 1,990 kWh | 68.66 kWh | |
| **Mar** | $500.00 | 2,310 kWh | 70.03 kWh | High Tier 2 |
| **Apr** | $360.00 | 1,680 kWh | 58.00 kWh | **Dropped (Optimized)** |

### 🔍 Key Findings
- **Tier 2 Threshold**: Passing the baseline threshold triggers higher rates.
- **Optimization Effect**: Disabling high-power appliances resulted in a significant drop in the monthly bill.

## 💡 Decisions & Conclusions
- Keep monthly usage below the Tier 2 threshold to avoid premium pricing.
- Implement optimized schedules for heavy appliances.
